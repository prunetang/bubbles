# Bubble Trails

A lightweight Windows desktop effect that sends colorful trails of small, translucent bubbles across your screen.

## About

Bubbles follow randomly moving paths, shifting between smooth, slow movement and sudden zips in every direction. Their colors and sizes vary continuously, and they fade quickly. Occasionally, a bubble displays a random number from **1–24**.

The overlay has a transparent background and translucent bubbles, so your desktop remains visible. Mouse clicks pass through to the apps underneath. It runs independently without reacting to your mouse or keyboard.

- No menus or control panels
- No sound
- Supports multiple monitors
- One Python file

## Requirements

- Windows 10 or 11
- Python 3.10 or newer
- PySide6

## Installation

Download **bubble_trails.pyw**, then open Command Prompt and install its dependency:

`py -m pip install PySide6`

## Run

Double-click **bubble_trails.pyw**.

Alternatively, open Command Prompt in its folder and run:

`py bubble_trails.pyw`

## Exit

Press **Ctrl + Alt + Shift + Backspace**.

If the app reports that the shortcut is unavailable, close any other running instance and try again.
